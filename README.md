# NCT Content Intelligence Dashboard

An interactive web-based newsroom analytics and content intelligence dashboard.

### Live Website
🌐 **[Visit NCT Content Intelligence Dashboard](https://nctanalysis.ai.studio/)**

### Features
- Newsroom performance overview
- Guest appearance analytics

- Personality tracking
- Weekend and special programming analysis
- Interactive filters and data visualisations
